Русский интерфейс omp на основе официальной версии 0.9.22.

- Русские подписи, настройки, меню, подсказки и сообщения приложения; MCP, Skills и согласованные технические названия остаются на английском.
- Выбор English / Русский / 中文 через кнопку с глобусом. Выбранный язык сохраняется и синхронизируется между окнами.
- Отдельный канал обновлений `ru`: официальные сборки без перевода не заменяют эту версию через встроенное обновление.
- Неизменённый Core из официального релиза 0.9.22; происхождение и контрольные суммы закреплены в ru-sidecar-source.json.

Для установки используйте файл `setup.exe`. Он использует существующий профиль omp, сохраняя настройки и сессии. Portable предназначен для запуска без установки; автоматическую установку обновлений поддерживает установленная NSIS-версия.

Изменения оригинала поступают в fork через проверяемые PR. Новые версии выпускаются после дополнения перевода и тестирования. Официальное включение русского языка предложено автору в PR https://github.com/nornzach/oh-my-pi-gui/pull/16.
